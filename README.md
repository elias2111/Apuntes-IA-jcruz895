# 📚 Apuntes y Ejercicios: Redes Neuronales Artificiales (ANN)

Este repositorio contiene **notas de clase, apuntes de estudio y cuadernos prácticos** sobre Inteligencia Artificial y *Deep Learning*. El objetivo principal de estos materiales es servir como guía de aprendizaje y referencia rápida para el estudio de arquitecturas fundamentales de Redes Neuronales Artificiales.

---

## 📂 Contenido de los Apuntes

| Cuaderno | Tema / Contenido |
| :--- | :--- |
| **`Avanzada_Cuaderno_1_ANN_El_Perceptron.ipynb`** | Fundamentos teóricos del Perceptrón, arquitectura básica y prueba de concepto. |
| **`Cuanderno_1_1_Perceptron_con_Sklearn.ipynb`** | Ejercicios prácticos e implementación del Perceptrón utilizando la librería `scikit-learn`. |
| **`Avanzada_Cuaderno_2_ANN_Red_Neuronal_sklearn_keras_tensorflow.ipynb`** | Construcción de Redes Neuronales Multicapa (MLP) comparando `Scikit-Learn`, `Keras` y `TensorFlow`. |

---

## 🧠 Conceptos Clave Cubiertos

- **Perceptrón Simple:** Entradas, pesos, sesgo (bias) y función de activación.
- **Modelos Básicos de ML:** Clasificación lineal y límites de decisión con Scikit-Learn.
- **Redes Neuronales Profundas:** Capas ocultas, optimizadores, funciones de pérdida (*loss functions*) e hiperparámetros en Keras y TensorFlow.
